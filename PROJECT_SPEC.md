# µAeroTrack project specification

The canonical product scope and architecture are defined in
[`docs/project_brief_v2.md`](docs/project_brief_v2.md). The gated implementation
sequence is defined in
[`docs/implementation_plan_v2.md`](docs/implementation_plan_v2.md).

The project builds and measures a low-cost onboard aerial object detector and
multi-object tracker. The first flight MVP records perception results during
piloted flight and has no command path to the flight controller.
