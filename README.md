# µAeroVLM

µAeroVLM is a research project for building a very low-cost, fully local, language-conditioned autonomous quadcopter using microcontroller-class onboard compute.

The canonical requirements, design options, architecture, implementation sequence, testing gates, safety rules, and research plan are maintained in [PROJECT_SPEC.md](PROJECT_SPEC.md).

Start with section 4 for verified engineering requirements, section 6 for design options, section 17 for the first 14 days, and section 21 for the immediate next action.
